# Porte sull'Oscurità

Companion site for *Porte sull'Oscurità*, the Italian-language chronicle of the *Call of Cthulhu* (7th edition) scenarios of *Doors to Darkness*: chapters, investigators, NPCs, places and handouts. Live at [porte.ogreballerino.com](https://porte.ogreballerino.com).

Built on the shared engine of this repository: see the [root README](../../README.md) for development, and [`CLAUDE.md`](./CLAUDE.md) for this campaign's conventions.
