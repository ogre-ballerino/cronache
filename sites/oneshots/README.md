# La Bacheca dell'Ogre

Companion site for the Italian-language one-shots played at the [Ogre Ballerino](https://ogreballerino.com): every adventure is a notice pinned to a tavern quest board, with the characters who played it (some of them regulars), the NPCs they met and the places they went through. D&D 5e for now, ready for other game systems. Live at [oneshots.ogreballerino.com](https://oneshots.ogreballerino.com).

Built on the shared engine of this repository: see the [root README](../../README.md) for development, and [`CLAUDE.md`](./CLAUDE.md) for this site's conventions.
