# Curse of Strahd

Companion site for an Italian-language *Curse of Strahd* (D&D 5e) campaign: session journal, player characters, NPCs and places of Barovia, with a map of the places the party has reached. Live at [strahd.ogreballerino.com](https://strahd.ogreballerino.com).

Built on the shared engine of this repository: see the [root README](../../README.md) for development and the session pipeline, and [`CLAUDE.md`](./CLAUDE.md) for this campaign's conventions.
