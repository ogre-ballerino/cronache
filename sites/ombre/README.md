# L'Equilibrio delle Ombre

Companion site for *L'Equilibrio delle Ombre*, an ongoing Italian-language *Call of Cthulhu* (7th edition) campaign: chapters, investigators, NPCs, places and handouts. Live at [ombre.ogreballerino.com](https://ombre.ogreballerino.com).

Built on the shared engine of this repository: see the [root README](../../README.md) for development, and [`CLAUDE.md`](./CLAUDE.md) for this campaign's conventions.
